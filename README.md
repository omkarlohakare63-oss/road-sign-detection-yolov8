# Road Sign Detection using YOLOv8

A computer vision project for detecting and recognizing road signs using YOLOv8.

## Project Status

🚧 Currently under development.

## Technologies

- Python
- YOLOv8
- Ultralytics
- OpenCV
- NumPy
- Pandas
- Matplotlib

## Planned Features

- Road sign dataset preparation
- Image annotation
- YOLOv8 model training
- Model evaluation
- Road sign detection
- Real-time webcam detection
- Video detection
- Confidence score visualization
